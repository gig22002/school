# Simple Birdcall Flashcard Application

## Setup
Put .mp3 files into same directory of appplication.  
Make sure playsound3 is installed.

## Usage
Enter the number of options you want to select from. Choosing '0' will make it open ended, with no listed options.

Inputs are accepted in a variety of formats:  
For a listed example option of "black-capped-chickadee-song," the following answers are accepted:  
- The number of the given option, e.g. 2
- black-capped-chickadee-song (explicit file name)
- black-capped-chickadee (omit 'song' or 'call')
- black capped chickadee song (spaces, hypens, underlines, and pluses are acceptable)
- black capped chickadee
- bccs (acronym of black capped chickadee song)
- bcc (omit 'song'/'call')
